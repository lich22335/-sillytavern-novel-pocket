# 小说随身库（SillyTavern Novel Pocket）

一个给 SillyTavern 酒馆玩的轻量原文检索扩展：上传小说 TXT/Markdown，自动拆章节、分段；每轮聊天前根据最近消息自动检索少量相关原文，并作为参考注入提示词。**不需要额外模型、不生成摘要、不消耗额外的模型调用。**

## 安装（v0.1.1 手机入口修复）

1. 下载 `sillytavern-novel-pocket.zip`，解压得到 `sillytavern-novel-pocket` 文件夹。
2. 将**整个文件夹**复制到 SillyTavern 的 `public/scripts/extensions/third-party/` 目录。确保路径为 `public/scripts/extensions/third-party/sillytavern-novel-pocket/manifest.json`。
3. 刷新酒馆页面。在右下角找到「小说」按钮。
4. 进入一个已保存的角色聊天，点击「小说」→ 上传 TXT 小说。导入后会自动为当前聊天绑定并启用检索。
5. 可选择故事开始的章节（也可留空），然后直接聊天。插件每轮自动找相关原文供角色参考。
6. 在「检索测试」里输入人物或事件，确认能找到正确片段。

如果上传文件是 EPUB，先用阅读器或 Calibre 转成 TXT 再导入。中文 TXT 支持 UTF-8 和常见 GBK/GB18030 编码。

**GitHub 安装**：此 ZIP 是已准备好的扩展仓库结构，但尚未发布在 GitHub 上，因此**不能直接在酒馆的「安装扩展」中粘贴 ZIP 路径**。若把文件夹内容上传为 GitHub 仓库根目录，便可将该仓库 URL 粘贴到酒馆「扩展 → 安装扩展」。

## 使用说明

- 一个已保存的聊天绑定一本小说，其他聊天不会自动启用。
- 扩展检索只在当前浏览器本地进行（IndexedDB）。换浏览器、换手机或清除网站数据时，需要重新上传小说。
- 每次注入的是少数原著片段，不是整本书。大模型本身并没有真的读完全书。
- 默认每轮 5 段，原文合计不超过约 6200 字符。可在面板里改为 3/4/6/8 段并限制字数。
- 选中当前章节会略微优先这章，并至少提供该章开头一个片段；**不会自动推进章节**。
- 小说数据不会上传到额外服务，但每轮检索出的片段会随正常酒馆提示词发送给你配置的聊天模型服务商。
- 为避免重复注入，建议关闭酒馆 Vector Storage 的文件检索（本扩展独立工作）。

## 技术方案

- 纯前端 ES module；不需要额外数据库、Python、Node 扩展服务器或 Ollama。
- 使用中文连续双字（bigram）+ 英文词 + BM25 的本地文本检索，而**不是向量 Embedding 语义检索**。这是一版省事的检索增强原型，适合娱乐，不适合要求精确全书理解的场景。
- 首次导入按章节拆为约 950 字符片段，110 字符重叠。存储于浏览器 IndexedDB，索引在打开该书时在内存中重建。
- 使用官方的 `generate_interceptor` 和 `SillyTavern.getContext().setExtensionPrompt` 注入；不改动聊天消息和小说原文。

## 限制与测试情况

本版已进行 Node 核心检索单元测试和 JavaScript 语法检查，**尚未接入真实 SillyTavern 实例做端到端测试**；首次使用请先在不重要的聊天里检索测试并查看提示词。如酒馆版本改变扩展接口，可能需要小幅适配。

建议兼容 SillyTavern 1.17+。源码：`manifest.json` / `index.js` / `core.js` / `storage.js` / `style.css`。

## v0.1.1 手机界面修复

- 加入无依赖 `bootstrap.js` 入口，即使主模块导入失败，也会显示蓝色「小说」按钮并可点击查看具体错误。
- 入口使用内联样式，在 `style.css` 加载异常时仍能显示。
- 酒馆扩展设置页面新增「小说随身库 · 打开管理窗口」按钮，提供备用入口。
- 修复版安装后需 **更新扩展并刷新页面**；如果使用 GitHub 安装，确保仓库根目录包含 `bootstrap.js`，且 `manifest.json` 的 `js` 字段为 `bootstrap.js`。
- 这版未经真实手机酒馆端到端验证；若点击按钮出现报错，截图提示即可定位下一步。

## v0.1.2 手机操作

更新扩展并刷新页面，从扩展设置的「小说随身库 · 打开管理窗口」进入，点击「＋ 上传小说（TXT / Markdown）」选择文件。窗口顶部和底部均有文字关闭按钮，支持返回/Esc关闭。窗口使用原生 dialog 顶层显示，避免被其他酒馆弹窗遮挡。
