# 小说随身库 · Novel Pocket v0.2.1

SillyTavern 1.19 的本地小说扩展。导入 TXT/Markdown 一次，在不同角色聊天里选同一本书，每个聊天分别保存自己的剧情进度。支持顺序阅读和关键词检索，不使用额外摘要、Embedding API 或额外 AI 账号。

## 安装和更新

在酒馆「扩展 → 安装扩展」粘贴：

`https://github.com/lich22335/-sillytavern-novel-pocket`

已有用户更新扩展后刷新页面，管理窗口标题显示 `0.2.1`。入口是扩展设置中的「小说随身库 · 打开管理窗口」，同时提供浮动「小说」按钮。原有小说数据库保留，**无需重新上传**。

## 跟着原著玩

1. 打开一个已保存的角色聊天，进入小说管理窗口。
2. 上传 TXT，或在「本聊天使用的小说」选择之前导入的书。换角色卡只需重新选书，不要重复上传。
3. 用「按章节找片段」或输入段号点「查看」，通过上一段／下一段浏览完整原文。也可展开「用原文查找位置」粘贴场景结尾，切换定位候选看完整预览。确定后点「从预览的第 N 段开始」，才设为当前剧情起点并启用顺序模式。浏览本身不会改变进度。
4. 默认每轮给当前段及下一段，通常原文约 1900 字符，保留少量重叠；每段标注全文序号、总段数和章名，明确区分「当前进度」与「后续参考」。可改为 1 或 3 个连续片段，并受原文字数预算约束。
5. 在正常发送聊天消息时，若酒馆工具调用及中转均支持，AI 可调用读取工具获取后续，并在认为当前段剧情结束时调用推进工具。单纯预读不会改变进度。
6. 不支持工具调用、AI不调用工具或判断不合你意时，先浏览目标段，再点「从这里开始」。也可取消「允许 AI 读取后续并推进一段」，只用手动控制。

普通酒馆已支持工具接口，但需要在**聊天补全设置开启工具调用 / Function calling**，且中转正确转发工具参数和结果。窗口会显示酒馆当前是否支持；这不能证明具体中转一定可用。推荐用正常「发送」验证，酒馆自身的「继续生成 / continue」模式不会发起原生工具调用。

AI 工具使用当前聊天模型，不调用另一个模型。但取原文后继续回复会有正常模型用量，酒馆也可能保留工具结果记录；工具记录可能随聊天变长。默认一次只读一段，最多三段，酒馆自身限制工具递归次数。预算不足时少给完整片段，不截断原文后悄悄跳过未读内容。旧文件中超大单段会完整返回第一段，不严格压到预算内。

## 自由探索与预设

切换「关键词检索」时按最近对话匹配人物、地点、事件，默认五段，可能来自不同章节；这些段也标注全文序号。它不是语义向量检索，命中率有限。

默认原文插在主提示词之前，作为单独背景参考，不再附加剧情控制、隐瞒检索或写作格式要求。可改为最近玩家发言前的独立用户参考消息，不直接修改你的原话、角色卡或预设。最终顺序受酒馆提示词管理器设置影响；原著文风仍可能影响生成，位置调整不能保证完全隔离。可在酒馆提示词检查器核对实际请求。

## 数据和编号

小说数据保存在当前浏览器、当前酒馆地址的 IndexedDB；偏好、聊天绑定、进度保存在 localStorage。换浏览器、换设备或清除网站数据需要重新导入；同浏览器同地址换角色无需重传。不要为了更新插件清除网站数据。

切分先识别章节，再按约 950 字符、110 字符重叠切片，尽量在句末或换行处结束。全文第 N 段是原文顺序，并不保证每段恰好是一个完整事件。旧书在加载时直接按既有片段顺序编号，不重切，不破坏已有内容。

进度按聊天隔离。旧聊天无段号时从已选章节的首段开始；未选章节则从第一段开始。每次工具调用携带阅读会话标识，换聊天或换书之后，旧会话的工具参数会被拒绝。自动推进只接受下一段、必须已读取、携带当前段号，重复和过期调用不能跳段。

文件支持 UTF-8、常见 GBK/GB18030，20 MB 上限；EPUB 请先转 TXT。只会把提供的片段发送给你当前模型服务商。

## 开发和验证

`npm test`，无需下载依赖。当前 16 项自动测试覆盖原文切分、检索、注入位置、顺序窗口、定位、预读与推进分离、书尾和重复推进、原生工具注册、窗口控件串联及跨聊天隔离。窗口串联测试模拟 DOM、IndexedDB 与酒馆接口，**不等同于真实手机或中转端到端验证**。

`bootstrap.js`、`manifest.json` 均在仓库根目录。技术交接见 `HANDOFF.md`。

## v0.2.1 选段与预览

主界面保留选书、当前进度、章节浏览、上一段／下一段、段号查看、完整原文预览和确认起点。导入、AI推进及阅读设置、检索记录和删除收进折叠区。预览字号16px、行距1.85，独立滚动，正文不截断。修复纵向flex布局压缩控件的原因，让主内容滚动而非所有选项挤在一屏。小说与已保存进度保留。模拟接口串联测试增加超过1200字符完整预览、浏览不推进、确认推进、回到当前进度的验证；没有真实手机布局截图验证。
